# 蓝色认证体验设计规范

> 适用范围：`src/pages/auth/` 下的 uni-app 认证页面。视觉结构参考产品提供的移动端认证原型；原型中的绿色品牌交互已统一替换为蓝色，微信入口保留官方绿色。

## 1. 目标与边界

认证体验覆盖以下页面与前端状态：

- 账号密码登录：手机号、密码显隐、隐私政策确认、忘记密码、验证码登录入口。
- 验证码登录/注册：手机号校验、图形验证码弹层、60 秒倒计时与隐私政策确认。
- 微信小程序登录：读取后端 FAST/REALTIME 配置，获取微信已验证手机号和 `wx.login` 临时凭证后直接登录。
- 重置密码和设置密码。

微信小程序手机号直登已接入后端真实服务：前端将手机号授权凭证和 `wx.login` 凭证提交到 `POST /auth/login`，使用 `WECHAT_MINI_PHONE` 认证类型完成手机号解析、账号创建或归并、微信身份绑定与 Token 签发。普通手机号短信登录仍使用 `PHONE` 认证类型；注册、密码重置等其余流程仍未接入真实服务。

## 3. 排版、间距与控件

- 页面默认使用 `rpx`，移动端以单栏为基线。
- 主标题：`44rpx`、700 字重；说明文字：`24rpx`。
- 输入与主按钮高度：`88rpx`；输入框、按钮圆角：`44rpx`（胶囊样式）。
- 弹层圆角：`24rpx`；桌面端认证卡片圆角：`36rpx`。
- 输入框必须保留可见错误文案和红色边框，不能仅通过颜色表达错误。
- 密码显隐、隐私政策勾选、第三方入口均提供不小于 `88rpx` 的触达容器。

## 4. 响应式布局

| 视口 | 布局规则 |
| --- | --- |
| 小于 `768px` | 单栏认证页、居中标题与表单，匹配移动端原型的信息层级。 |
| 大于等于 `768px`（H5） | 左侧蓝色品牌展示区，右侧可滚动认证区域与白色表单卡片。 |
| 小程序 / App | 保持单栏；不依赖浏览器专属的桌面装饰能力。 |

安全区复用现有 UnoCSS `pt-safe`、`pb-safe`。认证页面使用自定义导航栏，以便提供原型中的返回与帮助区域。

## 6. 交互与表单状态

### 账号密码登录

- 手机号必须是 11 位中国大陆手机号；密码长度为 6-20 位。
- 用户未同意隐私政策时，账号登录和微信登录均显示明确错误并停止操作。
- 账号密码接口尚未接入，因此有效表单提交只显示“服务待接入”反馈。

### 验证码登录与重置密码

- 发送验证码前先校验手机号，再展示图形验证码弹层。
- 行为验证码校验成功后，请求 `GET /captcha/sms?phone=...&captchaType=blockPuzzle&captchaVerification=...`；短信接口成功后开始 60 秒倒计时。
- 普通手机号登录使用 `authType: "PHONE"`，微信小程序端可附带新获取的 `wxLoginCode` 关联微信身份。
- 设置密码等尚未接入的流程不修改 Token、账户或密码。

### 微信小程序登录

`src/service/auth/wechat-auth.ts` 负责获取 `wx.login()` 临时凭证，登录页负责微信手机号授权和登录态提交：

1. 页面请求 `GET /auth/wechat-mini/phone-login-config`，按 `FAST` 使用 `getPhoneNumber`，按 `REALTIME` 使用 `getRealtimePhoneNumber`；配置不可用时回退 `FAST`。
2. 用户已同意隐私政策时，底部微信入口直接唤起手机号授权；未同意时，隐私政策确认弹窗的确认按钮本身承载微信原生手机号授权。
3. 获得 `phoneCode` 后立即调用 `uni.login({ provider: 'weixin' })` 获取新鲜的 `wxLoginCode`。
4. 以 `clientId`、`authType: "WECHAT_MINI_PHONE"`、`phoneCode` 和 `wxLoginCode` 请求 `POST /auth/login`；后端使用微信验证后的手机号创建或归并账号并绑定微信身份。
5. 仅在服务端返回 Token 且当前登录尝试仍有效时调用 `useTokenStore().completeExternalLogin()`，随后按安全解析后的 redirect 返回来源页。
6. 用户取消手机号授权、微信凭证获取失败或后端校验失败时保留在登录页并显示可恢复错误，不再跳转独立短信绑定页。

## 7. 路由与安全

认证路由常量集中于 `src/router/config.ts`，包含登录、验证码登录/注册、重置密码、设置密码和隐私政策页。`src/utils/toLoginPage.ts` 使用同一 `LOGIN_PAGE`，避免 Token 失效时跳到已删除的 `/pages/login/index`。

`resolveAuthRedirect()` 仅接受以单个 `/` 开头的内部 uni-app 路由；缺失、损坏、外部 URL 或 `//` 协议相对 URL 都会回退至 `/pages/index/index`。

## 8. 无障碍与内容要求

- 输入框拥有明确 placeholder；错误文本紧邻对应输入框。
- 密码显示/隐藏和隐私政策确认带有语义化标签。
- 禁用按钮不可触发提交；异步操作应显示“处理中”。
- 不用仅颜色传达成功、错误、选中或禁用状态；必须配合文本或勾选标记。
- 文案必须明确区分“开发演示”与真实服务，尤其是短信、注册、绑定、重置密码和微信登录。
