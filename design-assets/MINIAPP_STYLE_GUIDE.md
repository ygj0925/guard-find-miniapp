# 泊之湾微信小程序样式规范

## 视觉方向

首页采用浅冰蓝背景、蓝紫主色、深蓝文字和白色内容层。页面保持轻量的房源信息密度，重点突出搜索、筛选、房源图片和价格。

## 颜色令牌

| 用途 | 值 |
| --- | --- |
| 页面底色 | `#EDF3FF` |
| 内容底色 | `#FFFFFF` |
| 主色 | `#5360FF` |
| 主色浅色 | `#A9B7FF` |
| 标题文字 | `#162650` |
| 正文文字 | `#536484` |
| 辅助文字 | `#7A869F` |
| 分割线 | `#E3E9F5` |
| 标签底色 | `#F1F4FC` |
| 成功状态 | `#2CA77A` |
| 警示状态 | `#D98A2B` |
| 错误状态 | `#D95B64` |

整页只使用蓝紫作为主操作色。状态色只用于状态本身，不用于装饰性按钮。

## 字号和行高

| 层级 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面首屏标题 | 30px（宽屏32px） | 800 | 37px |
| 区块标题 | 18px | 700 | 28px |
| 房源标题 | 17px（宽屏18px） | 700 | 24px |
| 正文 | 14px | 400 | 22px |
| 辅助说明 | 12px | 400 | 18px |
| 标签文字 | 12px | 500 | 18px |

大标题只用于页面首屏。房源列表和筛选控件遵循正文级字号，避免在小屏设备上挤压信息。

## 间距和圆角

- 基础间距使用 4px 倍数，常用间距为 8px、12px、16px、20px 和 24px。
- 房源卡片使用 24px 圆角，照片使用 16px 圆角。
- 首屏搜索框使用 58px 高度和 30px 圆角，分类按钮使用 52px 高度和胶囊圆角，筛选按钮使用 48px 高度。
- 主要操作按钮使用胶囊形圆角。
- 列表卡片之间使用 18px 间距。
- 页面左右安全边距使用 20px，窄屏时不低于 16px。

## 微信安全区

- 顶部内容必须避开状态栏和右上角胶囊。
- 自定义标题栏使用 `wx.getMenuButtonBoundingClientRect()` 计算胶囊底部，再给 8px 间距。
- 底部固定内容使用 `env(safe-area-inset-bottom)`。
- 绝对定位的城市、筛选和操作浮层必须设置独立层级，不能改变正文流式高度。

## 交互层级

- 页面标题行滚动后吸顶，并显示低透明度背景和轻阴影。
- 筛选浮层显示在筛选行下方，使用白色面板和轻阴影。
- 城市选择使用全屏弹层，提供搜索、当前定位、历史城市、热门城市和字母索引。
- 加载状态沿用内容卡片的骨架形状。
- 空状态和错误状态保留明确的恢复操作。

## 图片和图标

- 首页运营入口图标统一使用 `design-assets/icons` 中的透明 PNG，搜索、定位、收藏和底部导航使用 Carbon 线性图标。
- 房源图片使用真实房源图，加载失败时显示统一的空图占位。
- 图标容器和图片本身不要叠加两套不同圆角背景。
- 图标视觉尺寸按 24px、32px、48px 三档使用。

## 组件验收

- 同一页面的按钮、输入框、标签和卡片使用统一圆角规则。
- 文字颜色优先使用令牌，不能随页面局部新增近似蓝色。
- 任何下拉选择都不能推移房源列表。
- 在 320px、375px、390px 和 430px 宽度下检查标题、城市名和价格不溢出。
- 真机验收微信状态栏、胶囊、底部手势区和键盘弹出后的布局。

## 首页交互约定

- 首屏只保留标题、搜索、四类房源、城市与排序、房源卡片和地图找房，运营入口下移到房源列表后。
- 城市筛选胶囊点击城市名称打开全屏城市选择器，右侧箭头打开价格与租赁方式浮层，浮层使用绝对定位，不改变列表高度。
- 默认首屏展示“整套、单间、民宿、公寓”四类。点击后映射到现有租赁方式与房源类型接口，不改变接口字段。
- 地图找房按钮固定在底部导航上方，距离手势区使用安全区变量计算，避免遮挡底部导航和最后一张房源卡片。
